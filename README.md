# MiirTree

Локальный мультимедийный сценарный пульт для Android.

## v0.1
- Android / Kotlin / Jetpack Compose
- свободный рабочий холст
- перемещаемые узлы
- визуальные связи между узлами
- добавление новых узлов
- GitHub Actions для сборки debug APK

Дальше: локальное сохранение проектов, ручное соединение узлов, импорт изображений/видео/аудио, интерактивные переходы и вывод контента на телевизор.
